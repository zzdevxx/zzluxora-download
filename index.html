PANDUAN OPERASIONAL

Setup Panggung dalam 3 Langkah

Dirancang agar teknisi pencahayaan dapat menyambungkan konsol ke lampu DMX dalam hitungan menit.

01

Install Konsol ZZLUXORA

Jalankan ZZLUXORA-Setup-10.0.0.exe. Aplikasi terpasang ke folder pengguna tanpa prompt UAC dan langsung terbuka dalam kondisi bersih.

02

Hubungkan ke Node ESP32

Sambungkan laptop ke hotspot ARTNET-DMX (IP 192.168.4.1) atau jaringan WiFi gereja (zzlight.local), lalu pilih target IP di jendela Setting.

03

Patch Fixture & Aktifkan PLAY

Klik quick-patch 4x zzdree-36X di tab Address, muat audio di Analyze atau buka showfile .zlx, lalu tekan tombol PLAY untuk mulai mengirim DMX512.

PERTANYAAN TEKNIS

FAQ Operasional & Kompatibilitas

Sesuai aturan keamanan panggung, ZZLUXORA menerapkan transmisi Play-Gated. Pergerakan fader saat PLAY nonaktif hanya mengubah tampilan antarmuka tanpa memancarkan paket Art-Net UDP ke rig lampu.

Ya. Firmware esp32-artnet-dmx mematuhi protokol standar Art-Net 4 (OpCode 0x5000, ArtPoll/ArtPollReply) pada UDP port 6454 Universe 0, sehingga kompatibel dengan ZZLUXORA, QLC+, Resolume, maupun grandMA onPC.
